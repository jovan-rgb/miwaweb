Petunjuk koneksi Google Sheets
  1. Buat Google Sheet, lalu pilih Ekstensi → Apps Script.
  2. Salin kode dari file Code.gs ke editor Apps Script, lalu simpan.
  3. Pilih Deploy → New deployment → Web app. Jalankan sebagai akun pemilik sheet dan batasi akses hanya kepada pengguna yang berhak.
  4. Setujui izin yang diminta, deploy, lalu salin URL Web App yang berakhiran /exec.
  5. Tempel URL itu ke konstanta APPS_SCRIPT_URL di bagian bawah file index.html. Buka ulang aplikasi.

Perlindungan data: batasi akses Web App dan spreadsheet kepada tim yang berwenang. Jangan memilih akses publik untuk data pengkajian yang dapat mengidentifikasi warga.
