Petunjuk koneksi Google Sheets
  1. Buat Google Sheet, lalu pilih Ekstensi → Apps Script.
  2. Salin kode dari file Code.gs ke editor Apps Script, lalu simpan.
  3. Di Project Settings → Script Properties, tambahkan AUTHORIZED_EMAILS berisi alamat email anggota tim yang diizinkan, dipisahkan koma atau baris baru.
  4. Pilih Deploy → New deployment → Web app, jalankan sebagai akun pemilik sheet, dan batasi akses ke pengguna dalam domain Google Workspace tim. Jangan pilih Hanya saya atau akses publik.
  5. Setujui izin yang diminta, deploy, lalu salin URL Web App yang berakhiran /exec. Perbarui deployment setelah mengubah kode.
  6. Tempel URL itu ke konstanta APPS_SCRIPT_URL di bagian bawah file index.html. Pengguna harus login dengan akun Workspace yang alamatnya tercantum pada AUTHORIZED_EMAILS.

Perlindungan data: akses domain hanya membuka pintu ke pemeriksaan email allowlist pada skrip; hanya alamat yang tercantum di AUTHORIZED_EMAILS yang boleh membaca atau menulis. Jangan menghapus pemeriksaan ini atau memilih akses publik untuk data pengkajian.
